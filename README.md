# 红楼游园

首版可运行交互样板。以青绿立体园林为主视区，连接人物、精选情节与诗词题联。

## 本地运行

需要 Node.js 22.12+（本机使用 24）。

```sh
npm install
npm run dev
```

打开 http://localhost:5173 。本次已启动本地预览服务。

```sh
npm run build
npm run test
npx playwright test
```

浏览器测试默认使用本机 Google Chrome；其他环境可安装 Playwright Chromium 并调整 playwright.config.ts 的 channel。

## 本版能体验什么

- 真实 Three.js 园林：八处院落主建筑均为**阿里云百炼 Tripo-3D 生成的写实 3D 模型**（`useGLTF` 加载、自动缩放/落地），单栋约 1.1–1.4MB、共约 10MB；曲面屋顶、窗格、树木、竹林、水面、桥与游廊环绕。
- 院落索引与详情中的八幅独立示意小景，每处院落各有轮廓与象征植物；左侧索引小图为真实园景照片（苏州园林等）。
- 环境写实化：程序化草地贴图与石板园路、带树皮的深绿树木与圆冠、水面纹理与反光、柔和光照与轻雾；模型**加载期先显示程序化建筑、加载完替换真实模型**，并在进入园林时**预载全部模型**，缩短首屏等待（总包约 10MB）。
- 鼠标旋转、缩放、俯视/立体切换、全园复位、展开地图、院落标签和模型点选。
- 人物目录：18 位主线人物各有真实人物头像（87 版《红楼梦》演员形象）；点开人物可见身份、居所、关联情节与文字，并以 React Flow 呈现交互式人物关系图谱——可点击节点切换人物、拖动平移、滚轮缩放、按亲属/主仆/交往/情缘过滤、一键**全屏查看**，边上带关系文字（不单靠颜色）。
- 红楼诗文笺：诗词、食饮、药方三类条目（当前 诗词 17 / 食饮 10 / 药方 7），支持分类与检索、阅读正文与出处。
- 按姓名、雅号、院落名检索；人物目录跳转至关联院落。
- 五段情节联动；题额故事支持五站导览、播放/暂停、上一站/下一站。
- URL 保存地点与情节；手机院落抽屉和自适应详情。

## 样板边界

这不是完整 PRD 的最终版本。人物头像采用 87 版《红楼梦》真实演员形象（照片放在 `src/assets/portraits/<id>.jpg`，未放入者显示占位提示），关系图谱为编辑整理的示意，不承担考证。药方、食饮条文经摘录整理，正式发布前应逐条回原文复核。尚未补齐每人全部情节。本版人物入口以目录 + 详情页呈现。为便于展示经原文核查的题额路线，八个空间节点中以沁芳亭替代了 PRD 候选中的芦雪庵。第 40 回只展示沁芳亭的精选片段，不冒充整回路线。

园林为艺术示意，建筑造型和坐标不表示考证复原。生成模型为**程序化渲染的单栋写实古建**（阿里云百炼 Tripo-3D，`Tripo/Tripo-P1.0`），其造型、比例与相对位置为艺术重构，不代表考证复原；体积轻量（单栋约 1.1–1.4MB）。环境（树丛、草地、水面）已做写实化处理以与建筑协调。除潇湘馆水墨插画外，其余院落配图是示意。无后台、运行时 AI、账号系统或公开部署。

## 结构

- src/domain：领域模型（人物、关系、文学条目分类）与原文链接规则，不依赖界面或 Three.js。
- src/application：院落/人物检索、关系子图、故事筛选、上下文一致性用例。
- src/infrastructure：本版静态内容目录（人物、关系、诗词、食饮、药方、故事）。
- src/ui：React 页面、实时园林、院落小景、人物小像、关系图谱、相机与视觉样式。
- tests：领域规则与真实浏览器流程。

本版内容结构使用共享 ID 关联，未复制整段情节到人物记录。轻量项目合并了简单契约边界，未引入空目录或数据库。相机坐标与图谱节点坐标仅存在于表现层。
