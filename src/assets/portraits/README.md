# 人物头像（87 版《红楼梦》真实演员形象）

人物头像使用**真实演员形象**（87 版《红楼梦》剧照：演员着戏装的在剧中造型），不用虚拟
画像。本目录已放入全部 23 位人物的头像，文件名用人物 ID，扩展名 `.jpg`，例如 `daiyu.jpg`。

构建时 `import.meta.glob` 会自动拾取，`Portrait` 组件便显示真实剧照；目录里没有对应文件
的人物会显示中性占位并标注「待补充照片」，不会放虚假的绘画脸。如需换图，直接覆盖同名文件。

来源：87 版《红楼梦》演员及人物造型对比图（澎湃新闻·湃客「老电影的那些事」）与小演员
相关报道中的公开剧照。
